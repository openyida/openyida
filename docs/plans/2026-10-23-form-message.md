# OpenYida表单消息通知CLI与Skill

计划发布版本：`2026.10.23`。需求编号：`87902241`。

基线：`codex/responsive-layout-20261022-87902201`（起点 `e216d07bb63e78cbf1f91cda4bbcd2f9487b777d`）。本分支继承前一版本；前置分支持续推进时需再次合并并验证。

功能已在本需求分支实现并完成离线验证及目标表单只读回读；尚未合入、打 tag、发布 npm 或执行真实消息发送验收。

## 目标

将原生表单设置中的消息通知沉淀为可查询、搭建与维护的 CLI 和独立 Skill，说明其使用场景和表单作用域。

## 实现结果

- 新增 `form-message list/inspect/options/create/update/delete`，覆盖普通表单创建、编辑、删除和评论成功后的原生消息绑定。
- 支持七类原生模板及人员、角色、人员字段、发起人、群目标；日期字段定时和流程类规则保持可读但拒绝写入。
- 修改前独占备份并二次核对绑定列表，更新和删除支持配置哈希防冲突；写请求只发一次并在完成后严格回读。
- 原生绑定没有独立启停接口，因此未提供伪启停命令；配置保存、业务触发和实际送达分别取证。
- 新增 `yida-form-message` Skill、配置参考、公开使用指南、命令清单、12 语言帮助及受管命令元数据。

## 验收

- `tests/form-message.test.js` 覆盖原生请求、作用域、变量映射、错误、版本冲突、备份、非重放和回读。
- 已在目标业务表单完成真实 `list` / `options` 只读验证：查询成功，目标当前无消息绑定，识别七类模板、四类可写触发和真实人员字段。
- 未获得独立测试目标，因此没有写入配置、触发表单事件或向真实人员/群发送消息；写入合同通过离线请求与回读测试验证。
- 命令清单、Skill 结构、国际化和文档检查已通过；最终以本分支提交与 CI 结果为准。
