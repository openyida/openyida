# 千问办公链接展示

在千问办公中提供链接时，都按本规则处理，包括进度、提问、操作提示和最终回复。其他环境使用各自可用的展示方式。

## 选择展示工具

千问办公云端优先使用 `show_link` 工具，桌面端优先使用 `artifact_show_link` 工具。首选工具不可用时，使用当前会话可用的展示链接工具，并遵循该工具的使用要求。

## 展示链接

1. 使用本次操作或查询结果中已确认的完整链接，不自行拼接或修改。缺少链接时，先查询确认。
2. 按用户需要展示应用、页面、表单等入口，不额外展开无关链接。完整应用沿用已有的入口交付要求。
3. 提供链接前，先使用展示链接工具。同一轮中的相同链接只处理一次。
4. 无法确认展示结果时，不声称用户已经看到链接。直接发文字链接或打开浏览器，也不算完成工具展示。
5. 工具不可用、不支持该链接或展示失败时，保留原来的可点击链接。需要说明时，只说“链接暂时无法展示，可点击此处打开”。不要为补展示而重新创建内容或反复修改。

## 回复用户

只说明本轮完成了什么、链接用于什么，以及用户需要做什么。工具名称、参数和后台处理过程不写进用户回复；用户明确询问技术细节时再按需说明。

完成前，核对用户需要的入口是否都已提供。展示失败不改变已经完成的业务结果，也不能被说成展示成功。总结保持简短。
