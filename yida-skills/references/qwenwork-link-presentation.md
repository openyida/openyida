# 千问办公开发者后台链接展示

前台、业务后台、开发者管理后台的正常交付方式，以及对话中的宜搭操作和链接处理，都沿用原有规则。

只在每轮回复结束前，使用一次展示链接工具，展示当前宜搭应用的 `/admin` 开发者管理后台。

## 选择展示工具

千问办公云端优先使用 `show_link` 工具，桌面端优先使用 `artifact_show_link` 工具。首选工具不可用时，使用当前会话可用的展示链接工具。

## 展示规则

1. 确认本轮正在处理的宜搭应用，使用创建应用或查询应用结果中已确认的 `adminUrl`，不自行拼接地址。
2. 先按原有方式处理本轮业务和所需链接。前台、业务后台和过程中的链接不因本规则改成工具展示。
3. 本轮结束前，只对当前应用的开发者管理后台调用一次展示链接工具。不要把前台、工作台或某个页面的地址作为这次展示的目标。
4. 每轮最多调用一次。后续新一轮对话仍按本规则处理，不因为上轮已经展示过而省略。
5. 当前应用或开发者后台链接尚未确认时，保留本轮已完成的结果，不猜地址、不额外创建应用。用户明确排除开发者后台时，遵从用户要求。
6. 工具不可用或展示失败时，保留开发者后台的可点击链接，不反复调用或重新创建内容。

## 回复用户

只说明本轮完成了什么、入口用于什么，以及用户需要做什么。工具名称、参数和后台处理过程不写进用户回复；用户明确询问技术细节时再按需说明。

展示开发者后台不替代本轮原本需要交付的前台、业务后台或其他入口，也不代表已经验证用户的管理权限。
