# 场景：数据大屏 / 实时监控 / 态势屏

> 面向投屏和实时监控的沉浸式页面。它不是普通 dashboard 放大版。

## 场景定位

- **用户目标**：持续观察态势、发现异常、快速处置。
- **典型业务**：水质预警、物流态势、生产监控、园区安防、销售战情。

## 布局骨架

```
┌─────────────────────────────────────┐
│ 顶部：标题 + 时间 + 状态             │
├───────────┬─────────────────┬───────┤
│ 左信息塔   │ 中心态势图/地图    │ 右排行 │
│ KPI/雷达   │ 热点/流向/告警点   │ 占比   │
├───────────┴─────────────────┴───────┤
│ 底部：趋势 / 告警流 / 滚动动态        │
└─────────────────────────────────────┘
```

## 视觉规则

- 默认 `isRenderNav=false`，full-bleed。
- 可以使用深色底、网格、辉光和态势线，但所有效果服务数据。
- 中心必须有一个态势主体：地图、拓扑、流程、设备矩阵或核心趋势。
- 左右信息塔密度高，字号和对齐要稳定。

## 禁止

- 浅色卡片 dashboard 直接放大。
- 没有中心态势，只堆 KPI 和表格。
- 图表容器无高度导致空白。
- 高饱和颜色无语义乱用。
