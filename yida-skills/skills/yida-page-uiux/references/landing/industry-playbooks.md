# Landing 行业 Playbook

## 茶饮/餐饮/零售

- Hero 必须有产品或门店氛围图。
- 强调口味、体验、门店、加盟/购买路径。
- 色彩可以更鲜活，但语义色不乱用。

## 律所/咨询/金融

- 视觉克制，重信任、资质、案例、流程。
- 少用夸张渐变和大面积插画。
- 章节更偏“问题 → 方法 → 证明 → 咨询”。

## SaaS/企业服务

- Hero 可用产品界面或流程图。
- 强调效率、流程、集成、数据证明。
- CTA 指向试用、咨询或查看演示。

## 文旅/酒店/美业

- 图片是核心资产。
- Section 节奏更重场景、体验和口碑。
- 避免 B 端工作台式卡片堆。
