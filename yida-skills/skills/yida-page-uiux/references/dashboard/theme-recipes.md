# Dashboard 主题配方

## 宜搭应用主题风格

- 主色来自 `--color-brand1-*`。
- 图表色组来自 `--color-group`。
- 成功/警告/错误保持语义色，不跟随品牌色漂移。
- 普通 dashboard 可以是浅底业务风；数据大屏可以是深色沉浸，但光效和主色仍从运行态主题派生。

## 主题强度

| 强度 | 用法 |
| --- | --- |
| 克制 | 常规经营看板，白/浅灰底，主色只给关键动作和选中态 |
| 强调 | 管理驾驶舱，核心 KPI 和洞察区可使用主色面 |
| 沉浸 | 数据大屏，深色底 + 主题光效 + 高对比图表 |

## 禁止

- 所有 KPI 卡都刷成同一种绿色/蓝色。
- 用高饱和撞色表示普通分类。
- 把“宜搭应用主题风格”理解成只能浅色卡片。
