# 闪记材料处理规则

当前 Agent 读取材料、提取事实并生成 PRD。以下规则适用于已有文本、截图识别结果、听记转写和会议摘要。

## 读取与分段

1. 确认材料边界，保留原始文件或本轮读取结果。
2. 材料能完整放入当前上下文时直接处理。超出上下文时，按话题或发言边界分段读取。
3. 每段记录来源位置、角色、业务动作、字段、条件、数值、明确决策和待确认项。
4. 每段读取结束后核对尾部，保证下一段接续。没有换行的长段落也要完整覆盖。
5. 合并事实时按业务模块组织，保留独立规则与例外。输出较长时逐章写入 PRD，再统一核对章节和跨模块关系。

分段大小取决于宿主的上下文能力。Agent 直接处理材料时不套用远端 CLI 的 6000 字符请求预算。

## 事实清单示例

| 来源 | 已确认事实 | 待确认内容 |
| --- | --- | --- |
| 转写第 1 段 | 普通员工只能查询库存 | 是否允许查看成本金额 |
| 转写第 2 段 | 领料审批被拒绝时不扣库存 | 审批通过后由哪个步骤扣减 |
| 会议摘要 | 每晚 20 点生成当日库存变动报表 | 统计截止时间、20 点以后的变动归属 |

统计时间范围需要业务确认。不得直接补成当天 00:00 到 23:59:59。

## 清理与冲突处理

- 可以清理口语填充词、重复空行和无业务含义的录音定位时间。
- 保留日期、业务发生时间、数量、金额、阈值、单位以及「不能」「仅」「除外」等限定。
- 会议摘要用于定位重点；与转写不一致时，保留两个来源并列为待确认。
- 后出现的讨论不自动视为最终决策。仅在材料明确表达撤回、修改或最终确认时替换旧事实。
- 未确认的字段、状态、权限或自动化写为建议，并保留对应的待确认事项。

## 产物核对

使用 [PRD 输出模板](flash-note-prd-template.md) 组织内容，并检查：

1. 原始材料首、中、尾的关键事实都能对应到 PRD。
2. 角色的可见范围与操作权限准确。
3. 数值、时间、状态、例外和失败分支准确。
4. 建议与已确认事实明确区分，缺失信息列入待确认。
5. 所有章节写入完成，表格和代码围栏闭合，文档结尾完整。
6. 保存后读取产物核对，再返回文件位置及关键待确认项。
