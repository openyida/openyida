# 角色旅程

应用级体验要先回答“谁进来做什么”。

## 角色卡

```markdown
- 角色：经销商
- 第一入口：经销商数据看板
- 高频任务：查看 GMV / 补货风险 / 活动转化 / 巡店建议
- 需要页面：dashboard + list + detail
- 不需要页面：内部配置表单直接暴露在首屏
```

## 页面映射

| 角色需求 | 页面类型 |
| --- | --- |
| 了解品牌价值 | landing |
| 处理待办和入口 | workbench |
| 判断业务健康 | dashboard |
| 监控态势 | screen |
| 找对象和批处理 | list |
| 看单个对象全貌 | detail |

## 验收

- 每个核心角色至少有一个明确入口。
- 页面命名体现角色任务，不用泛化标题。
- 不为所有角色展示同一套入口密度。
