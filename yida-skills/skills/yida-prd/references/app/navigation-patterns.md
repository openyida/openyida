# 导航模式

## 平台导航

适合常规中后台、多页面业务系统。优先使用宜搭左侧导航分组，页面内容保持与平台主题融合。

规则：

- 门面页靠前，配置/录入类页面靠后。
- 同一角色的高频页面放同组。
- 同应用内页面优先在平台应用导航内切换；不要把一组同应用页面复制成自定义页里的快捷入口卡。
- 看板、工作台、列表、详情不要无序混排。

## 页面内导航壳

适合显式隐藏应用导航后的官网、门户、大屏、独立分享页。

规则：

- 默认不要在自定义页面里自建同级导航；只有用户明确要求页面内导航、自绘导航、隐藏平台导航或独立全屏体验时才使用。
- 默认生成页导航可见；页面内导航不自动隐藏平台导航，只有用户显式要求隐藏导航、无导航或独立全屏体验时，才进入隐藏导航设计分支。具体跳转参数由页面实现技能处理。
- 顶部导航适合官网/门户；侧边导航适合复杂后台；浮动胶囊适合沉浸展示。
- 页面内导航只负责当前沉浸体验，不替代平台真实导航管理。

## 混合导航

适合复杂应用：平台导航承载模块，页面内 tab 承载同页子视图。

规则：

- 平台层做跨模块跳转。
- 页面层做当前模块内切换。
- 不同时出现两套同级导航。
