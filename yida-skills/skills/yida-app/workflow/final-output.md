# 最终输出

本文件用于阶段 9。先判断完整应用是否完成，再输出用户能直接使用的结果。

## 完成条件

完整应用默认完成条件：

1. 主页面发布成功；
2. 轻量导航自动排序已执行，或给出明确 warning；
3. 核心普通表单已写入 1-3 条示例记录并 query 抽查，或说明跳过原因；
4. 输出 2-3 句业务交付总结；
5. 在业务总结之后给出一个可访问主入口链接；
6. 未继续执行可选后置动作。

本轮修改过页面源码但没有成功执行 `openyida publish <source> <appType> <displayPageFormUuid>` 时，完整应用未完成；最终回复只说明本地源码修改和未发布原因。

## 主入口选择

| 场景 | 主入口 |
| --- | --- |
| 新增、修改或发布某个具体页面 | 当前页面 URL |
| 完整应用、表单、流程、权限、主题、导航或批量资源场景 | `{base_url}/{appType}/workbench` |

## 回复格式

先写 2-3 句业务交付总结，再给一个主入口链接。默认不输出资源 ID 表格、长列表、管理态链接、CDN 构建产物 URL 或中间文件 URL。

推荐写法：

已完成订单、客户和商品等核心业务表单，并发布首页、订单管理和库存看板等入口页面。当前应用已支持订单录入、库存预警、销售统计、表单提交入口和详情查看，示例记录、轻量导航排序与表单详情样式也已就绪。

主入口：`{base_url}/{appType}/workbench`
