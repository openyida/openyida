# {{PROJECT_NAME}} design.md

## 1. 风格摘要

**主题色浅灰导航 · 低饱和轻面板（warm-rail-muted-panels）**

独立导航与近白工作区形成柔和的明度分区。白色面板有轻圆角、浅边线和几乎不可察的底部投影，主文字与选中标记接近黑色；品牌色从项目输入派生，强调面积很小。页面的辨识度来自温和底色、清楚的对齐和细线图形，而不是大色块。出现统计内容时，大数字、低饱和主题色趋势图和局部彩色分段建立阅读焦点。

| 核心特征             | 可见表现                                                                             | 主要偏离风险                                           |
| -------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| 导航与内容各自配色   | 导航与选中项使用专用配色；工作区保持近白                                             | 将导航配色覆盖到内容区，或让整行选中抢走业务焦点       |
| 微弱边界、平整表面   | 白卡片靠细线、微阴影和留白划分，工具是小圆角描边矩形                                 | 给普通面板加厚阴影、玻璃模糊或明显材质                 |
| 近黑选中与弱品牌强调 | 激活项可用细黑顶线、反白小图标；明显品牌强调只进入必要标志和数据，框架保留低比例染色 | 把所有激活项、标题和按钮都变成品牌实底                 |
| 数据图形轻而准确     | 有相应数据时，使用低饱和主题色水平顶线、渐隐填充、虚线对照或紫蓝分段                 | 用高饱和大面积图表、无数据含义的纹理或随机分块制造装饰 |
| 数值与说明分层       | 关键数值放大，周期、单位和比较说明使用主题浅灰，涨跌标记保持紧凑                     | 过粗字重、过浅关键文字或符号与单位不一致               |

页面数量、功能和内容由实际需求确定。普通表单或列表通过浅色框架、白色轻边面板、克制的图标和文字层级即可体现主题；不要求每页具备趋势图、统计指标或状态条。

## 2. 页面视觉系统

### 2.1 表面、区块与层次

层次优先来自背景微差、边界与留白。局部阴影只提供轻微分离感，不让页面变成一组高悬卡片。以下线宽、阴影和图形局部尺寸属于实施推断，不把图片导出尺寸当作 CSS 尺寸。

| 对象                                         | 背景与必要前景                                                                 | 边界、形状与阴影                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| 应用根背景                                   | `--pod-app-root-bg-color`，背景图由 `--pod-app-root-bg-image` 控制             | 默认无图；背景图若启用，只作用于应用根节点                       |
| 页面画布                                     | `--pod-page-bg-color`，自定义页使用 `--oyd-page-bg`                            | 平整近白，不铺纹理、不做全局模糊                                 |
| 已有应用页头                                 | `--pod-card-bg-color`，文字用 `--color-text1-4`                                | 底部一条 `--color-line1-1`；无明显投影                           |
| 一级面板、表单主容器与详情面板               | `--pod-card-bg-color`，主文字用 `--color-text1-4`                              | 1px `--color-line1-1`，`--corner-5`；可用局部微阴影              |
| 表格正文                                     | `--pod-table-cell-color`                                                       | 连续白面，横向分隔，拼接处使用 `--corner-zero`                   |
| 内部分段与中性选中                           | 默认延续白面；需要选中填充时用 `--color-fill1-2`，较重填充用 `--color-fill1-3` | 空白或单条分隔线优先，避免多层完整卡片嵌套                       |
| 下拉、浮层、气泡、弹窗、弹出日历、导航弹出层 | `--color-fill1-5`；正文用 `--color-text1-4`，说明用 `--color-text1-10`         | `--corner-3`；小浮层可用 `--shadow-1`，模态弹窗可用 `--shadow-2` |
| 抽屉                                         | `--color-fill1-5`；文字按浅色表面配套                                          | 露出角用 `--corner-5`，贴边处直角；必要时使用 `--shadow-2`       |
| 图表读数浮卡                                 | `--color-fill1-5`；主数值用 `--color-text1-4`，日期与说明用 `--color-text1-10` | `--corner-3`、细边框和局部弱投影，保持小体量                     |
| 简短 Tooltip                                 | `--color-fill1-10` 配 `--color-text1-5`                                        | 固定深底浅字，`--corner-3`；不与白色数据浮卡混用                 |

常驻面板的局部微阴影为 `0 1px 3px rgba(37,37,37,0.035)`；图表读数可使用 `0 5px 14px rgba(37,37,37,0.07)`。二者为弱化层次的实施推断，不能直接升级到大范围投影。`--shadow-3` 保留为完整平台档位，本主题未指定默认使用对象。

主题色外围仅在项目明确需要演示衬底或画布外框时启用，可用品牌色露出薄边；普通业务视口默认完整使用可用空间，不强制每页四周留主题色边框。外框位置与宽度属于项目页面设计，不将其写成全局导航或卡片背景。

### 2.2 应用导航

低饱和浅灰导航承托白色选中项，短间距、小圆角和细线延续工作区的轻量秩序。

常驻导航优先沿用平台原始样式，通过主题文字、背景与字重区分状态。菜单 border、box-shadow 是可选覆盖，没有明确用途就不声明；不为了统一风格给每项加框或投影。普通入口融入同一侧栏，按连续目录组织；分组靠留白与文字层级，不把导航复制成输入框、独立按钮或卡片堆叠。内容卡片、主按钮和表单可以使用更强的形状与材质，同一主题不意味着所有组件装饰强度相同。业务确有触控或特殊展示需求时，在本 design.md 调整并验收，不在运行时限制项目自定义值。

菜单圆角可通过 --pod-nav-menu-item-radius 与内容层级配套。只有明确需要自定义边界时才声明 --pod-nav-menu-item-border、--pod-nav-menu-item-hover-border、--pod-nav-menu-item-selected-border，并检查状态切换不引起文字跳动；省略时保留平台原始表现。

导航与应用框架、表单、自定义页面和详情页共用设计语言。先按业务入口安排菜单、分组、搜索、品牌区与常用操作，再一起确定导航与正文的明暗、表面、字体、边界、圆角和密度。平台导航使用真实页面菜单；自绘导航按同一套导航 Token 实现。导航外观属于这份完整应用主题，颜色、三态边框、圆角、阴影与表单、详情和自定义页面一起设计。业务决定入口组织、操作频率与交互需求；主题决定这些需求的视觉表达。主色只是颜色角色之一，辅助色和材质色可以独立存在；仅显式 var 引用建立联动，不按主色批量染色。项目更换配色时，回到同一份 design.md 成组调整实际受影响的 Token，并核对五类界面的整体搭配。

导航底色使用 --pod-shell-theme-bg-color；普通、悬停和选中文字分别使用 --pod-nav-item-text-color、--pod-nav-item-text-hover-color、--pod-nav-item-text-selected-color；悬停和选中背景使用 --pod-nav-menu-bg-hover-color、--pod-nav-menu-bg-selected-color。图标跟随对应文字状态，当前入口同时用背景或字重表达。

菜单高度、圆角与间距使用 --pod-nav-menu-item-height、--pod-nav-menu-item-radius、--pod-nav-menu-gap；搜索、品牌区、分组和操作优先沿用平台已有的变量绑定，navigation 分组只声明本主题需要覆盖的差异。弹出菜单的底色、文字与搜索状态成组配套，导航与内容可以分别选择明暗。选中项通常沿用平台样式；仅需额外位置标记时才声明 --pod-nav-menu-item-selected-shadow，显式 none 用于有意关闭阴影。省略时不生成额外 box-shadow 规则；该 Token 独立于导航明暗。菜单高度、文字行高、内距和框架留白一起调整，给外阴影、长标题与键盘焦点留出空间。

桌面检查菜单、搜索、选中态与表单的协调；折叠后保留可识别图标和入口名称；窄屏保持菜单可展开、当前页面可定位、键盘焦点可见。提交、编辑、详情与自定义页都沿用这一导航设计。

### 2.3 页面标题与操作

应用已有页头保持白面、左侧标题与右侧轻量图标操作。页内已有日期、比较范围和项目筛选直接放在画布上，靠对齐和组间留白组织，不额外套一张完整工具栏卡片。比较范围可以用简短连接说明夹在两个控件之间；没有比较任务时不保留该结构。

页面标题使用全局标题规格，与说明之间留 `--s-1` 或 `--s-2`，与主要内容之间留 `--s-5` 或 `--s-6`。当页头已明确标识当前任务，页面内部不再重复同名标题。

面板标题左对齐，帮助图标可紧随标题，筛选或详情操作对齐另一侧。工具组内部使用 `--s-2`，不同任务组之间使用 `--s-4` 或 `--s-5`。空间不足时整组换行并保留次序，不通过缩字号、压扁按钮或省略单位容纳。

### 2.4 排版、间距与形状

使用 `--font-family-base`，字体属于中性无衬线实现方案，不假定截图使用的准确字体。全局字体和间距保持固定基线，独立指标使用页面层排版。

| 文字角色                   | 字号、字重与行高                                                                     | 颜色与安排                                              |
| -------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| 页面或页头标题             | `--font-size-subhead`、`--font-weight-subhead`、`--font-lineheight-subhead`          | `--color-text1-4`，克制加重                             |
| 面板标题、重要分组名       | `--font-size-body-2`、`--font-weight-body-2`、`--font-lineheight-body-2`             | `--color-text1-4`，不增加有色标题底条                   |
| 正文、标签、按钮和输入     | `--font-size-body-1`、`--font-weight-body-1`、`--font-lineheight-body-1`             | 主文字色；次级标签可用 `--color-text1-10`               |
| 表格与对齐明细             | `--font-size-table`、`--font-weight-table`、`--font-lineheight-table`                | 表头用 `--color-text1-10`，重要数据用 `--color-text1-4` |
| 日期、单位、比较口径、坐标 | `--font-size-caption`、`--font-weight-caption`、`--font-lineheight-caption`          | `--color-text1-3`；关键说明提高到 `--color-text1-10`    |
| 关键数值                   | `--oyd-font-size-metric`、`--oyd-font-weight-metric`、`--oyd-font-lineheight-metric` | `--color-text1-4`；单位与变化值低于主数值层级           |

数字启用等宽数字特性，金额、百分比、单位和精度保持一致。主数值与单位沿基线对齐，数值列对齐以便比较。缺失值、零和不适用分别表达，不以示例中的金额、百分比或日期作为固定格式。

页面内边距使用 `--s-6` 或 `--s-8`；一级区块之间使用 `--s-5` 或 `--s-6`；面板内边距使用 `--s-5` 或 `--s-6`；行内间隔使用 `--s-2` 或 `--s-3`。图形区可用留白增强清晰度，但高度必须由真实任务和视口确定，不要求所有页面保留大图表空区。

圆角依对象选择：连续指标带和拼接表格用 `--corner-zero`，小图标盒与分段条用 `--corner-1`，输入、菜单与按钮用 `--corner-2`，浮层用 `--corner-3`，内部组合容器用 `--corner-4`，一级面板和抽屉用 `--corner-5`。圆形头像、圆点和图表焦点用 `--corner-circle`；`--corner-semicircle` 只用于任务需要的开关或圆头进度，普通工具按钮保持圆角矩形。

### 2.5 色彩、图标与点缀

品牌色由项目输入确定，强调面积有限；中性选中仍可采用近黑，与品牌强调分工。导航、画布、边线和说明中的偏色灰都由同一品牌种子与中性灰派生，换色时维持浅深层级。

主趋势使用 `--oyd-chart-primary`，真实对照使用 `--oyd-chart-comparison`，以线型辅助区分。独立容量图采用 `--oyd-capacity-color` 与 `--oyd-capacity-outline`；它们不是平台信息状态色，也不随品牌 hover 或 active 改变。独立分类标识与错误、警告、成功、信息状态分别管理，不因颜色相近就互相借用。

内容工具与明细图标采用一致的细描边家族，尺寸以 `--s-4` 至 `--s-5` 为主，线宽约 1.5px（推断）。导航为紧凑实心识别符号，内容操作为细线符号，两种家族按用途区分，不在同类按钮中混搭。少量指标图标可放在 `--color-fill1-3` 小方底盒中；激活时底盒变为近黑、图标反白，形状不变。

彩色点缀集中在真实分类、风险分布、方向反馈或容量图中，普通标题、工具和卡片边界保持中性。填充渐变仅用于真实趋势图的向下消隐；斜纹仅表示明确定义的余量或非占用区。不添加纸张噪声、全局模糊、发光、玻璃效果或无数据意义的装饰折线。

## 3. 基础组件表达

以下是组件存在时的表达规范，不是必建清单。未列出的组件按任务结构、表面、文字、形状和状态推导，不增设同义变量。

### 面板与分组

白色面板采用浅边框、适度圆角和局部微阴影。标题与操作同一行，内部用间距、细线和文字层级组织；简单表单和详情也使用同一表面，不为了复现图形场景新增指标。

属于同一任务的图表与指标可以共享外容器，内部通过一条横线分开，不重复套两张卡片。独立任务才拆分面板，分区数量和布局由项目需求确定。

### 按钮、输入与选择控件

普通按钮为白面、`--color-line1-2` 细边框和 `--corner-2`，前景用 `--color-text1-10` 或 `--color-text1-4`。高度按角色使用 `--s-7` 至 `--s-10`；紧凑工具优先 `--s-8`，更重要操作采用较高档。图标按钮宽高相等，仍保持圆角矩形；筛选、详情、搜索和更多操作不默认变成胶囊。

品牌实底只用于确需强调的主要动作，背景用 `--color-brand1-6`，沿用浅色前景 `--oyd-on-dark-color`；不能让同一工具组的每个动作都成为主按钮。下拉箭头与主体之间可加一条弱竖分隔，但只有真正的分裂按钮才将两侧表现为独立操作。

输入默认表面使用 `--color-fill1-1`，不借用同为白色的卡片或 pop-up 背景。高度采用 `--s-8` 至 `--s-10`，圆角用 `--corner-2`，边框用 `--color-line1-2`，placeholder 用 `--color-text1-10`。日期图标、范围文本与展开箭头沿同一水平中线排布；选项列表使用白色覆盖层与对应前景。

### 指标、选择状态与图标盒

指标标签位于主数值上方，变化及比较说明在下方，层间距使用 `--s-2`。单位降低为说明规格，正负符号属于数值本身；箭头只在存在真实方向关系时出现。

连体指标的激活状态可使用约 2px 的近黑顶线、`--color-fill1-2` 轻底面和近黑反白图标盒（线宽为推断）。顶线与深图标使用 `--color-text1-4`，反白图标使用 `--oyd-on-dark-color`，不复用短 Tooltip 的专用配对。普通未激活图标盒用 `--color-fill1-3` 与 `--color-text1-10`。

这种选择样式只应用于真实可切换项，不给普通静态指标加交互暗示；当前项文字、指示线和关联数据必须同步。

### 表格与独立明细列表

表格正文使用 `--pod-table-cell-color`，通过 `var(--pod-card-bg-color)` 跟随卡片表面。表头可使用 `--color-fill1-2` 与 `--color-text1-10`；默认只用浅横分隔线，不加厚网格、彩色表头或悬浮行卡片。行内垂直留白用 `--s-3` 或 `--s-4`，多行文本允许自然增高。

独立统计明细可以采用“识别图标与名称、当前数值、方向与变化量”对齐排列，名称优先获得空间，数值与变化量分别沿固定列轴对齐。不是每项都要有状态标签，不能用颜色替代完整名称。头像和分类图标仅在真实对象需要识别时出现。

### 图表、分段与读数

绘图区使用白色表面，水平网格使用 `--color-line1-1`，坐标与单位使用说明层级。主线约 1–1.5px，对照线约 1px 并采用约 4px 线段、4px 间隔的虚线（均为推断）；不默认画满节点。当前焦点可用小实心圆与浅色外环，圆心落在真实数据位置。

读数浮卡以深色数值和次级周期说明形成两层；多序列时增加与图例一致的名称或色点。坐标、图形位置、单位、格式化值和提示框必须同源；不能让百分比落点与提示框显示不同量级，也不能把计数指标附上无关货币单位。

普通进度轨道使用 `--color-fill1-3`，长度与真实分母对应。分段条的每段来自真实分类、阶段或阈值，宽度由数据决定；若存在间隙，分段宽度从扣除间隙后的有效绘制宽度计算，不让装饰间距改变占比。中性斜纹使用 `--color-line1-2` 绘制在浅轨道上，不能把缺失或未知值直接当作剩余容量。

变化好坏与变化方向分别判定。上升、下降先用数值与箭头表达，只有业务已有评价规则时才使用相应语义色。错误、警告、成功和信息沿用平台已有状态，不为主题重建同义状态变量；未给出具体变量名时按语义对接。

### 状态与反馈

| 状态                             | 视觉处理                                                                                                    |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Hover                            | 中性控件保持 `--color-fill1-1`，通过边界和文字加深表达；品牌操作使用 `--color-brand1-1`。普通卡片不整体抬升 |
| Active / pressed                 | 中性操作使用 `--color-fill1-2`，品牌操作使用 `--color-brand1-9`，不缩放改变布局                             |
| Selected                         | 中性浅底配近黑标记，真实指标选择用顶线和小图标反白；导航使用六项专用配色                                    |
| Focus                            | 使用约 2px 品牌色轮廓及可见外间隔（推断），不只依赖微弱阴影                                                 |
| Disabled                         | 使用 `--color-text1-2` 或 `--color-brand1-10`，保留文字轮廓；正常次级信息不按禁用态处理                     |
| Error / warning / success / info | 沿用平台语义色，配必要文字与图标；错误输入保持结构稳定并显示说明                                            |
| Loading / empty                  | 骨架使用 `--color-fill1-3`；空态以简短说明与已有可用操作表达，不绘制假走势或随机占比                        |

轻量过渡可使用约 120–160ms 的颜色、透明度变化（推断），不增加持续播放的数字动画。未展示的输入、焦点、错误和加载状态是由基础规则推导的实施方案。

### 表单组件与版式结构

原生表单与详情通过 appearance.native-form明确接入本主题：输入基础面使用 --color-fill1-1，边界使用 --color-line1-2，控件和只读数据框使用 --corner-2；焦点使用品牌交互角色。表单主面延续页面画布，操作底栏使用卡片表面与 --corner-5，详情保持正文前景与控件密度，不额外添加默认胶囊底栏或数据框阴影。项目有其他材质与状态需求时，在同一份 design.md 中调整对应 Token。

表单使用与自定义页面相同的应用全局样式，字体、色彩、表面、边界、圆角、密度和状态延续本主题。表单支持在顶部、左侧、主体、右侧和字段之间组合 Tab/切换、按钮组/操作入口、图片/图形、状态区、标题与 `Divider`、`ColumnContainer`、辅助内容和业务字段。各组件承担导航、操作、视觉焦点、反馈、层级、节奏、装饰或采集作用。普通业务分组和章节分隔使用 `Divider`，横向字段组合使用 `ColumnContainer`。每张表单在项目 `design.md` 写清组件位置与作用、列比例、标签位置、字段与章节间距、底栏、详情延续和窄屏重排。

## 4. 特色表达配方

### R1 分周期顶线、淡填充与虚线对照

**适用内容：** 时间被划分为明确周期，每个周期有一个真实代表值，适合表达该区间内的统计水平；第二条线只在存在真实对照序列时出现。

**继承基础：** 图表坐标、系列色、浅网格、白色读数浮卡和数据同源规则。

**特殊组合：** 每个周期顶部是一段独立的水平实线，其高度由该周期值决定，线段间形成阶梯式节奏；不默认用竖线连接相邻顶线，也不把这些区域画成圆角柱。线下区域从 `--oyd-chart-area-start` 向同色透明端垂直渐隐至共同基线。真实对照以细虚线跨周期展开，不使用面积填充。当前周期文字加深，落点显示小圆，读数卡位于附近并避免遮挡焦点。

**无匹配时：** 连续瞬时数据使用适当的普通线图，只有单序列则省略虚线；没有周期统计或图表需求则不渲染，不复制示例月份、曲线或读数。

### R2 与趋势图连体的指标选择带

**适用内容：** 多个真实指标共享同一趋势视图，且需要通过选择指标更新图形；只展示静态摘要时不赋予切换含义。

**继承基础：** 白色轻边框面板、指标排版、近黑激活标记与图标盒规则。

**特殊组合：** 趋势图下方紧接一排指标选择项，共享外层面板边界，中间仅一条横分隔线，没有独立卡片间距。每项内部依次为图标与标签、大数值、变化说明，当前项顶部显示近黑细线并将图标盒反白。数量取决于真实指标，不固定为四项。切换时标题、量纲、轴域、图例、数据和读数一并更新。

**无匹配时：** 静态摘要保持普通指标表达，不出现激活顶线；图表与指标无关联时分别按任务组织，不能为保留连体外观伪造交互。

### R3 分布横条、图例与对齐明细

**适用内容：** 数据是同一总体下可加总的互斥部分，需要同时看到总体分布与相关条目明细。只有真实风险等级才采用警示或稳定的语义配色。

**继承基础：** 独立指标、分段宽度计算、平台状态语义与统计明细对齐规则。

**特殊组合：** 总体摘要位于上方，下面排列较细的分段横条，段间留窄缝，每段使用 `--corner-1`。图例紧随条形，以圆点和文字对应分类；下方明细按名称、数值、变化对齐。异常、关注与稳定等已定义状态可使用相应平台语义色；不带评价含义的普通类别改用独立分类色。总体摘要若与分段占比口径不同，必须标明各自含义。

**无匹配时：** 非互斥数据使用独立对比，不强行加总为百分比；只有总数则显示普通摘要，没有明细则省略列表，不为了完整造型新增条目。

### R4 紫蓝占用分段与斜纹余量

**适用内容：** 存在明确总量、已占用值与可计算余量；需要额外分段时，还必须有真实阶段或分项贡献。单一百分比不自动推导多个小块。

**继承基础：** 数据容量色、进度轨道、分段比例、图形读数与中性斜纹规则。

**特殊组合：** 已占用部分用 `--oyd-capacity-color`，边界用 `--oyd-capacity-outline`，区块采用 `--corner-1`；可用约 1px 的白色低透明度内沿帮助辨认，不制作厚重立体效果。余量区域为浅轨道上的约 45° 细斜纹，间距约 5–7px、线宽约 1px（推断）。真实阶段边界或阈值可用细竖向引线、顶部小圆点与读数标注；线的位置、分块宽度和百分比全部从同一比例尺计算。

**无匹配时：** 没有阶段则使用单段占用条；总量未知时不画余量，缺失数据不当成未使用。没有容量类内容时完全省略该图形，不用随机小块装饰空白区。

## 5. 项目应用与调整规则

### 变量、平台与规则优先级

YAML 是变量值的唯一事实源，正文定义消费关系。全局变量供原生与自定义页面使用，本模板的扩展包含趋势、独立容量与分类颜色、指标排版。按分组递归读取以 `--` 开头的标量叶子，不把分组名称拼入变量名；平台基础与项目扩展均在主题中声明，可无环引用，并按实际设计补充变量。

导航六色独立成组确定，浅色导航不改变下拉或图表浮卡的白色表面。原生导航只配置开放颜色，自绘导航才应用相应形状和分组表达。背景、输入、卡片与 pop-up 即使同色也不混用职责。局部图形尺寸和弱阴影只在其对象上应用，不反向修改固定字体、间距或阴影档位。

需求决定内容和功能，平台限定可实现能力，主题决定视觉机制。条件配方不能覆盖自然内容增长、真实数据关系和明确平台限制。既有平台状态按语义接入，未提供变量名时不编造接口。

### 品牌色、表面派生与数据色实例化

- 色彩来源：{{COLOR_SOURCE}}。
- `{{PRIMARY_COLOR}}` 是唯一品牌种子，由项目输入与色彩来源确定，不设固定兜底色。主要强调与低比例表面染色分别消费相应派生角色，保持界面的明暗和视觉占比。
- 品牌七档分别对应悬停、平台预留浅色、派生浅色、派生深色、主色、按下和禁用。公式中的基底与比例以 YAML 为准，`--color-brand1-3`、`--color-brand1-5` 保留主题色浅深语义，需要它们的框架或导航角色通过引用消费。
- sRGB 混合逐通道执行 `round(种子通道 × 种子占比 + 基底通道 × 基底占比)`，通道为 0–255，比例相加为 100%，输出六位十六进制；不使用线性光转换。半透明面积色保留目标颜色 RGB 三通道，仅按公式设置 alpha，透明终点使用同一 RGB，避免渐变染黑。
- 主趋势、对照、同主题分类与所有偏色灰由品牌种子和无色相中性基底生成。容量紫蓝及独立橙、蓝分类保持其非主题数据语义；平台状态色按实际含义使用，不受品牌换色影响。
- 导航颜色按品牌引用和中性值成组解析，不能直接引用内容 Text 或 Fill。容量色不借给信息提示，项目分类橙色不借给告警；同色不意味着共享业务含义。
- 项目实例化时把生成标记替换成实际值，沿用设计稿确定的浅线、虚线、辅助文字和品牌按钮前景层级，不额外加深文字或动态切换黑白前景。

### 项目页面设计

只为实际需求里的页面填入确定设计，不沿用参考材料的品牌、菜单数、指标数、业务字段和样例数据。每页包含以下结果：

- **页面内容：** 页面名称、主要任务、真实字段、数据、操作与筛选范围。
- **首屏印象：** 第一焦点及其构图方式，说明独立导航、近白画布、文字层级与局部颜色怎样服务阅读。
- **布局安排：** 各区块位置、主次、实际宽度、列数、高度、对齐与窄屏重排顺序；明确哪些内容共享容器，哪些自然增长，不强制复制两栏或四指标布局。
- **视觉表达：** 面板、表单、集合、状态与图形如何应用基础规则；采用特色配方时说明编号、位置和适用数据关系。
- **标志性时刻：** 一处具体静态画面或真实交互反馈，交代位置或触发条件、视觉表现和任务价值，可与首屏焦点相同。
