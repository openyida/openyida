# {{PROJECT_NAME}} design.md

## 1. 风格摘要

**柔光深面 · Soft Spectral Panels**

近黑画布与独立配色的导航构成壳层，稍亮的主题暗面托起大圆角面板，边界轻薄，内部留白稳定。文字以灰白建立主次，品牌实心控件采用亮底深字。需要读数时，细定位线、浅色节点与很小的光晕形成局部焦点；其他区域保持平整安静。

| 核心特征 | 可见表现 | 主要偏离风险 |
| --- | --- | --- |
| 低饱和主题暗面层次 | 近黑壳层与稍亮的主题内容卡分开，弱轮廓围合圆润大面板 | 高比例主色铺满背景或抹平表面明暗差，会破坏层次 |
| 大面柔圆、控件紧凑 | 外卡圆角明显，输入和操作小圆角，图形在面板内充分展开 | 所有对象使用同一圆角，或让每条记录独立成卡，会削弱形状分工 |
| 品牌操作与稀疏数据亮色 | 主要交互使用品牌底和既定深色前景，酸黄与暗红只标真实数据系列 | 把数据色解释成成功／错误，或将整张卡填成品牌渐变 |
| 读数处的局部亮点 | 光点、细竖线与小读数气泡强调一个确定位置 | 大范围霓虹、持续呼吸动画或多处同时发光，会破坏注意力层级 |

表面、文字、形状与操作规则在普通表单、列表和详情中也应成立。多曲线、微图、矩阵、时间条和媒体说明仅在有相应内容时启用，不以保留画面为理由新增数据或功能。

## 2. 页面视觉系统

YAML 维护变量值，正文维护角色关系。主题暗面、偏色灰和同色图形均从主色与无色相灰基底生成；无色相中性值标注 `neutral-gray`，独立分类色保留明确的数据角色。局部尺寸和未展示的状态是实施推断，不以图像导出倍率改变全局字体。

### 2.1 表面、区块与层次

| 对象 | 背景及前景 | 边界、圆角与阴影 |
| --- | --- | --- |
| 应用根背景 | `--pod-app-root-bg-color` 与 `--pod-app-root-bg-image`；背景图只作用于根节点 | 默认近黑无背景图；外部绿光、模糊背景和展示留白不进入应用 |
| 页面画布 | `--pod-page-bg-color`；自定义页用 `--oyd-page-bg` 单向桥接 | 贴边部分用 `--corner-zero`，以留白分区 |
| 一级卡片、表单与详情主容器 | `--pod-card-bg-color`；主前景 `--color-text1-4`，说明 `--color-text1-3` | `--corner-5`，`--color-line1-1` 细轮廓，无明显外投影 |
| 内部分段与辅助面 | 优先沿用所在表面，必要弱填充使用 `--color-fill1-1` | 留白或 `--color-line1-1` 分隔；独立子区最多使用 `--corner-4`，不无限套卡 |
| 表格表头与正文 | 表头弱填充 `--color-fill1-1`、文字 `--color-text1-10`；正文 `--pod-table-cell-color` 跟随卡片 | 内部保持连续拼接，只在外壳保留圆角 |
| 下拉、气泡、弹出日历、弹窗和导航弹出层 | `--color-fill1-5`；主文字 `--color-text1-4`、说明 `--color-text1-3` | `--corner-3`、`--color-line1-2`；小浮层用 `--shadow-1`，弹窗用 `--shadow-2` |
| 抽屉 | `--color-fill1-5` 及配套内容前景 | 外露角 `--corner-5`，贴边角归零；`--color-line1-2`、`--shadow-2` |
| 图表读数卡 | `--color-fill1-5`；数值 `--color-text1-4`、单位／时间 `--color-text1-3` | 通常 `--corner-3`；仅单行短读数可用 `--corner-semicircle`，必要时 `--shadow-1` |
| 短 Tooltip | 固定 `--color-fill1-10` 与 `--color-text1-5` 配对 | `--corner-3`，与图表读数卡分开消费 |

画布与面板保留明确层差：页面为近黑，导航独立配色，卡片用品牌深色变体，读数浮层再略亮一档。卡片内部的图形直接绘在该表面上，不另铺黑色绘图区；搜索框保留自己的深色填充，快捷键底盒用 `--color-fill1-3`。

边界建议 1 CSS px（推断），只在暗面边缘形成细弱轮廓。表面层次依靠色差与轮廓，不借助玻璃模糊、双重倒角或大面积光晕；`--shadow-3` 保留为平台档位，主题默认不启用。根背景不继承到卡片、表格和输入。

### 2.2 应用导航

导航按项目确定的明暗成组配色，独立于内容画布。背景使用 `--pod-shell-theme-bg-color`，普通文字与图标使用 `--pod-nav-item-text-color`；悬停文字与背景使用 `--pod-nav-item-text-hover-color`、`--pod-nav-menu-bg-hover-color`，选中文字与背景使用 `--pod-nav-item-text-selected-color`、`--pod-nav-menu-bg-selected-color`。图标跟随对应文字状态，颜色以项目 tokens 为准。

原生导航只配置六项颜色角色，结构、尺寸、排序和折叠由平台处理；需要主题色的导航值直接引用对应 Brand Token，不绑定内容区 Text 或 Fill。导航与内容各自保持项目确定的明暗配对，共享品牌来源不合并两者职责。

仅当项目已确定自绘图标导航时，采用紧凑竖向轨道：选中命中区使用 `--s-10` 见方、`--corner-3`，普通线性图标不设彩底，分组以留白和短横线区分。图标保持名称提示，提示沿用短 Tooltip 配对；需要常驻文字的项目采用带文字菜单，不为套用主题隐藏名称。

轨道中的分类色点、开关、退出或通知只在对应真实功能存在时出现，不把色块当装饰。导航弹出层消费 `--color-fill1-5` 及内容前景，不直接继承主题选中表面。品牌变化仅按已有引用同步主题色，保留导航既定的文字和底色配对。

### 2.3 页面标题与操作

标题区与黑色画布连成一体，不强制再包卡。页面标题沿用 subhead 规格，搜索与已有主操作按阅读顺序排列，组内间距 `--s-3` 至 `--s-4`；缺少标题、搜索或状态时不留空壳。

已有并列的短摘要可在页头用细线和留白分组，轮廓可采用轻微弧肩连接（推断）；它们仍是信息区，不因造型近似 Tab 就暗示切换行为。已有实时提示可用短胶囊承载状态点与文字，状态必须来自真实数据，不能自动把红色点解释成实时或成功。

空间不足时摘要与操作换行，保持标题优先。面板标题使用普通图标与文字，尾部更多、筛选和图例只服务实际内容；图例和动作不能互相混淆。

### 2.4 排版、间距与形状

全局采用 `--font-family-base`，中文回退到可用系统无衬线。数值启用等宽数字特性，保持单位与精度一致；普通文本不改为等宽字体。

| 角色 | 字号 / 字重 / 行高 | 前景 |
| --- | --- | --- |
| 页面标题 | `--font-size-subhead` / `--font-weight-subhead` / `--font-lineheight-subhead` | `--color-text1-4` |
| 面板标题与重要名称 | `--font-size-body-2` / `--font-weight-body-2` / `--font-lineheight-body-2` | `--color-text1-4` |
| 正文、字段标签与操作 | `--font-size-body-1` / `--font-weight-body-1` / `--font-lineheight-body-1` | 主要内容 `--color-text1-4`，说明 `--color-text1-3` |
| 表格 | `--font-size-table` / `--font-weight-table` / `--font-lineheight-table` | 正文 `--color-text1-4`，表头 `--color-text1-10` |
| 元信息、图例、单位与坐标 | `--font-size-caption` / `--font-weight-caption` / `--font-lineheight-caption` | `--color-text1-3`，不降为禁用灰 |
| 重点指标 | `--oyd-font-size-metric` / `--oyd-font-weight-metric` / `--oyd-font-lineheight-metric` | `--color-text1-4` |

页面边距使用 `--s-5` 至 `--s-6`，卡片之间 `--s-4`，独立区段之间 `--s-6`；普通卡片内边距 `--s-5`，内容紧凑时使用 `--s-4`。标题与主体间隔 `--s-4`，同组信息间隔 `--s-2`，连续两行元信息之间 `--s-1`。视觉密度通过布局和留白调整，不缩小固定字体。

外卡、表单容器用 `--corner-5`，独立媒体或内部子区用 `--corner-4`，浮层用 `--corner-3`，输入、按钮与普通菜单用 `--corner-2`，微型方块和图例用 `--corner-1`。头像与圆点用 `--corner-circle`；周期标签、单行读数和真实需要的圆按钮可用 `--corner-semicircle`，其他对象不一律胶囊化。

各页的列数、比例、高度与必要等高对象由第五部分确定；内容自然增长，不要求统一卡片高度或独立内部滚动。

### 2.5 色彩、图标与点缀

品牌种子用于主要操作、必要交互焦点、主题暗面、偏色灰及主题图形。表面使用低比例主色混合无色相基底，控制染色强度；按钮固定采用设计稿确定的深色前景。

`--oyd-chart-series-1`、`--oyd-chart-series-2` 是品牌同源的数据浅色与中间色；`--oyd-chart-series-3`、`--oyd-chart-series-4` 是独立酸黄与低饱和红分类色。它们不等于四个固定业务类别，也不等于信息、成功或错误。图例、线条、点与读数在同一系列内保持一致，线型可辅助辨识。更多系列需要项目另行确定可区分映射，不循环套色。

成功、错误、警告与信息反馈使用平台已有语义；尚无平台变量名时只描述语义，不在页面层复制同义状态色。`--oyd-chart-focus` 仅定位当前读数，不能充当额外序列。

热力尺度使用 `--oyd-heat-low` 至 `--oyd-heat-high`，实心单元保持低于品牌操作的明度，独立于交互 hover、selected、disabled；`--oyd-missing-pattern` 表示项目已明确的缺失编码，不能等同于零值。

图标采用同一家族的细线轮廓，建议 18–20 CSS px、线宽 1.5 CSS px（推断）；导航主图标可适度增大。一般不设底盒，只有已成组的媒体元信息等内容可采用弱填充小盒。

局部光晕仅围绕当前读数点：使用 `--oyd-chart-focus` 的低透明叠色，建议不透明度 16%、扩散半径 6 CSS px（推断），不沿整条曲线持续发光。面积微图可在曲线与真实基线之间以本序列色从 12% 透明度向 0 渐隐（推断），裁切在绘图区。没有数据的背景不增加随机曲线、点阵、网格或光效。

## 3. 基础组件表达

本节规定组件存在时的表达，不构成必须拥有的组件清单。未列出的组件按任务结构、表面、文字、控件形状和状态推导。

### 面板、数值与微图

面板继承大圆角与弱轮廓；标题用线图标和文字清晰定位，已有图例或辅助动作在尾部排列。主体保留稳定内边距，不让曲线或图片压住文字。数值单元由名称、主要读数和口径说明组成，图形与数字顺序服从实际内容，不要求每张卡布局相同。

微图只能编码真实的小规模序列：连续观测可用折线或面积线，阶梯线用于分段恒定或离散切换，短柱用于离散数量，点阵须说明每点的计量或分组方式。没有对应序列时只显示数值和说明；不为凑图形新增数据类别或伪造走势。

变化量必须有真实基期，正负号、箭头与文案方向一致。占比须明确分子分母、是否互斥以及舍入策略；超过百分之百的增长率或倍数不能当作有上限的参与率。标题汇总与图内量纲不同但确有业务关系时分别标注，不能用百分比读数冒充计数坐标上的值。

### 按钮、输入与表单

| 组件 | 表达规则 |
| --- | --- |
| 主操作 | 背景 `--color-brand1-6`，自绘前景固定使用 `--oyd-on-accent-color`；常态、悬停和按下均保持设计稿的亮底深字关系，原生按钮沿用同一配对 |
| 中性操作 | 背景 `--color-fill1-1` 或透明，前景 `--color-text1-4`，边界 `--color-line1-2`；需要较重填充时用 `--color-fill1-3` |
| 图标操作 | 与相邻文本动作同尺度，常规 `--corner-2`；仅真正圆形操作使用 `--corner-semicircle` |
| 输入、搜索、筛选与选择器 | 基础背景 `--color-fill1-1`，输入文字 `--color-text1-4`，placeholder `--color-text1-10`，边界 `--color-line1-2`，圆角 `--corner-2` |
| 多行输入 | 沿用输入角色，按内容增长；工具区与正文以 `--s-3` 留白分开 |

按钮高度按用途选 `--s-7` 至 `--s-10`，普通操作为 `--s-8`；输入与筛选选 `--s-8` 至 `--s-10`，默认 `--s-9`。输入不借用卡片或 pop-up 背景；显示快捷键提示时必须有对应真实能力，不能照抄示例键位。

表单标签贴近输入，间距 `--s-2`，字段间隔 `--s-4`，独立分组间隔 `--s-6`。说明用正常可读的辅助前景，错误信息采用平台错误语义；大外壳内部不逐字段包成新卡片。

### 表格、列表与信息单元

表格正文消费 `--pod-table-cell-color`，通过 `var(--pod-card-bg-color)` 跟随卡片；表头背景 `--color-fill1-1`，前景 `--color-text1-10`。使用弱横分隔线，内部单元格保持连续比较，不逐格大圆角。行内上下留白 `--s-3`，左右 `--s-4`，文本左对齐、数值右对齐；仅对真实可排序列显示排序标识。

独立列表采用主文案、必要的次行信息与细分隔，允许自然换行。确有图片或头像时才使用对应素材；没有时使用清楚的文本或中性标识。含多个属性的信息单元可将图标、字段名与数值排成短行，小图标底使用 `--color-fill1-1`，不要增加一组彩色盒。

普通状态标签采用平台状态色与文字，小范围填充或描边即可；全行染色、每条记录独立投影和大面积品牌标签不属于默认表达。

### 图形与交互状态

图例、图形、读数与可读明细来自同一数据源；每条系列的颜色和线型保持稳定。轴刻度按真实数值有序排列，倒置坐标仅在真实任务要求且明确标识时采用。时间轴使用有效日期、明确时区和统计区间；时间筛选变化必须同时更新数据、轴与摘要。

序列曲线可用不产生额外极值的平滑插值，离散变化仍保留阶梯或折线。非焦点系列可以降低视觉重量，但不能把有效数据淡到不可辨；必要时通过线型、直接标签和选择反馈加强区分，不绘制伪造背景曲线。

基础进度轨道使用 `--color-fill1-3`，完成区域使用符合真实语义的品牌或平台状态色；需有有效目标和当前量，不能拿热力尺度或 hover 色替代进度角色。

| 状态 | 表达 |
| --- | --- |
| Hover | 中性透明对象用 `--color-fill1-1`，已有同底色控件加强文字或边界；品牌按钮用 `--color-brand1-1` |
| Active | 中性对象用 `--color-fill1-2`，品牌按钮用 `--color-brand1-9`；不改变布局 |
| Focus | 清楚的品牌轮廓，建议线宽 2 CSS px、偏移 2 CSS px（推断）；控件焦点不借用图表光点语义 |
| Selected | 中性选中用 `--color-fill1-2` 配合文字或勾选；需要明确实心强调的周期选择使用品牌底和既定深色前景；导航使用独立六色 |
| Disabled | `--color-text1-2` 及对应禁用表面，品牌操作用品牌禁用角色；禁用态不保留可操作高亮 |
| Error / Warning / Success / Info | 平台状态前景、图标和文字共同表达；酸黄与暗红图表色不自动承担这些含义 |
| Loading / Empty / Missing | 中性占位或明确说明；缺失样本与零值区分，不用随机数据填图 |

轻量颜色过渡建议 120–180 ms（推断）。图表定位点在有效选择发生时出现，不持续呼吸；普通卡片不悬浮缩放。覆盖层内的输入、悬停和选中仍消费各自角色，不直接继承导航配色。

## 4. 特色表达配方

### R1 曲线定位线与局部读数

**适用内容：** 真实有序序列需要查看某一时点或类别的值，且选择位置与数据项存在明确映射；多序列比较需有共同横轴与兼容量纲。

**继承基础：** 采用第三部分图形规则、2.5 的序列色与主题局部光点、2.1 的数据读数表面。

**特殊组合：** 从选定横轴位置绘制细竖向定位线，交点保留原系列颜色，并以 `--oyd-chart-focus` 小圆环或光点强调。读数卡靠近交点，显示系列、实际值、单位和时点；当前横轴标签可用品牌色短胶囊呼应。折线建议 1.5–2 CSS px、定位线 1 CSS px、焦点外径 6 CSS px（推断）。读数较多时使用正常浮层，不强塞进单行胶囊；线与点不改变真实图形几何。

选择变化时光点、定位线、横轴标签、读数和相关摘要同步更新。左右移动标记仅在实际支持移动选择时出现，不把静态图表做成虚假滑块。多序列交点不同，浮层须分别标识对应系列，不将焦点颜色当成新系列。

**无匹配时：** 无交互需求时保留普通图形与可读标签；无法映射到真实值时不显示精确读数。缺失点显示缺失，禁止自动补成零或从曲线造型反推数据。

### R2 共用时间轴的区间条

**适用内容：** 有真实起止时间和类别，需跨对象或周期比较状态占用、持续时间或活动区间。

**继承基础：** 使用基础图形与文字规则、2.5 的系列调色板，承载面保持统一主题暗面。

**特殊组合：** 每行在同一时间轴上放置实际区间条，条高建议 `--s-4`，行间留白 `--s-2`（推断），外露角使用 `--corner-1`。起止位置由时间戳映射，横向长度表达时长；颜色只表示类别，不再同时编码相同的时长值。所有行使用相同时间范围，空白代表无区间时需有明确说明。

仅在真实数据是可相加的组成量时，项目才将该区域确定为堆叠横条；此时轴单位改成实际数量，颜色、图例、总量和条长统一，不再保留时间刻度。区间图与堆叠图是不同数据任务，实例化必须选定一种。重叠区间用可辨的分轨或实际任务所需方式表达，不能顺次拼接伪造成持续时间。

**无匹配时：** 只有总量而无时间区间时使用普通条形或数值列表；类别不互斥时不能画成组成堆叠。不能为保持图形外观把消息数、百分比与小时放在同一条轴上。

### R3 有缺失标记的测量矩阵

**适用内容：** 两个明确维度构成网格，每个交叉单元有同口径测量值，且数据能够区分已测零值、未知和不适用。

**继承基础：** 使用第三部分数据规则、2.5 的热力色阶和缺失纹理，单元使用 `--corner-1`。

**特殊组合：** 方形或近方形单元等距排列，间距建议 `--s-1`（推断）。在明确的共同数值域 [a,b] 且 b > a 下，t = clamp((值 − a) / (b − a), 0, 1)，在 `--oyd-heat-low` 和 `--oyd-heat-high` 间按 t 做编码后 sRGB 逐通道线性插值。图例显示真实范围和单位；越界值在明细说明，不隐瞒截色处理。不同页面需要比较时共用尺度，不能逐行自行归一化。

斜纹表示缺失是本主题的可选实施推断，只有项目采用此含义时才启用：以 `--oyd-missing-pattern` 在卡片底上绘制约 135°、线宽 1 CSS px、周期 4 CSS px 的纹理，并在图例明确“无数据”。已测零值使用真实数值尺度，不能同样画斜纹；不适用需另有清楚标记。当前单元可用品牌轮廓和读数卡高亮，但不改变原数值填充。

轴标签有序、与筛选周期一致，小时需保持同一时间制度并注明时区；不能一边选择周，一边仍展示含义未变的月份轴。稀疏数据不靠重复填充方格制造密度。

**无匹配时：** 无共同单位、无完整维度关系或不支持缺失判断时使用列表或普通分类图；数据全同值时显示明确的单值图例，不对零宽数值域执行插值。平台无法表达斜纹时用明确的缺失符号与图例，不退化为“零值同色”。

### R4 融入面板的媒体说明

**适用内容：** 实际对象具有可用图片与需要展示的相关属性，并有明确的查看或后续动作。

**继承基础：** 沿用面板圆角、信息单元、正文层级与按钮表达，不依赖任何图表配方。

**特殊组合：** 图片和说明位于同一个主题暗面容器，图片裁切与外壳圆角一致，文本区按标题、属性短行、已有动作排列。素材具备透明背景或可融入深底时，可让主体直接接近卡片底面；使用正常照片时采用合适裁切，不强行抠图或虚构人物。属性以小图标、字段名和数值组织，主操作使用品牌底及既定的 `--oyd-on-accent-color` 深色前景。

图片比例、左右顺序、裁切焦点及窄屏重排在项目页设计中确定，文字不得被图片压住。素材本身的色彩可保留，不能为匹配主题给整页叠加光雾。不要沿用示例人物、姓名、活动主题或评分。

**无匹配时：** 无图片时使用普通信息面板，不添加虚构肖像；只有图片而无相关内容时按实际媒体任务设计，不凑属性。无真实动作时不显示演示按钮，也不为了配方新增媒体板块。

## 5. 项目应用与调整规则

### 变量与项目换色

YAML 是已声明变量的唯一数值来源。全局变量供原生与自定义页消费，本模板的扩展包含独立亮底前景、图表序列、读数点、热力尺度、缺失纹理及重点数值规格。递归读取以 `--` 开头的标量叶子，分组名不拼入变量名；不重复定义，平台基础与项目扩展均在主题中声明，可无环引用，并按实际设计补充变量。

需求决定内容，平台约束限定能力，主题规定视觉表达。原生导航仅配置六色，自绘导航沿用已确定结构；条件配方不能覆盖真实内容增长、测量口径或平台限制。

- 色彩来源：{{COLOR_SOURCE}}。
- 品牌种子为 `{{PRIMARY_COLOR}}`。没有品牌输入时从项目已选品牌或明确的色彩来源确定并记录，不保留固定色相兜底；用户给定种子不静默替换。
- 品牌派生公式以 YAML 为准：将种子与基底解析为 8 位 sRGB，逐通道取 round(a × seed + b × base)，a + b = 1，限制为 0–255 后输出六位十六进制。直接混合编码后的 sRGB，不执行线性光转换；项目文档替换全部生成标记。
- 七个 Brand Token 保留各自用途；appearance 的主题角色引用对应浅深变体。卡片使用 `--color-brand1-5` 的深色变体，由 `--pod-card-bg-color` 承接表面职责；`--color-brand1-10` 仅服务品牌禁用状态。近黑画布保持中性，导航使用项目配色，主题暗面、偏色灰、同色数据序列、焦点和热力尺度随主色重算；酸黄、暗红分类及平台状态保留自身语义。
- 导航六项保持独立角色并通过 Brand 引用同步主题色，不引用内容 Text／Fill。基础表面 `--color-white`、内容表面和 pop-up 保留暗色模式及既定前景，导航按项目选择成组配色；换主色不自动改换明暗模式。
- 文字、导航和品牌操作保留设计稿的底色、前景与状态配对，不按主色亮度自动挑选黑白前景、反转明暗或修改中性色值。图形保留直接读数、线型和边界等既定表达，主题派生仅按 YAML 的固定比例生成。

局部推断参数可按平台能力调整，保留低饱和主题暗底、大圆角、实心品牌交互与局部读数亮点的关系。字号和间距沿全局固定档位；不得为图形丰富度补造曲线、日期、媒体或业务指标。
