# 主题应用自检

主题选择统一使用 [共享主题选择规则](theme-selection.md)。本文件只检查选中主题如何落到当前页面，不再另选一套气质方向、强制第二选择或按固定差异数量改写主题。

## 平台约束

1. 页面在自身运行上下文消费应用主题变量，主操作和交互强调与应用主题一致；独立品牌页、自绘壳和沉浸页通过布局、材质、素材及辅助视觉体现差异。
2. 不依赖 `fonts.googleapis.com`。使用主题字体角色与可用系统字体回退，中文字体可用 `-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif`；远程字体仅使用已验证的 `g.alicdn.com` 资源。
3. 数据页、列表、工具和详情以业务内容与操作为主，装饰不干扰信息阅读。
4. 本文件不产出 JSX，也不替代 `design.md`；实现阶段读取项目设计与实现技能。
5. 默认浅色内容画布；暗色需要用户明确要求或已确认方向。导航明暗独立，不因深色导航把内容画布一并变暗。

## 五项应用检查

| 维度 | 检查内容 |
| --- | --- |
| 色彩角色 | 项目主色与主题的交互、数据、状态角色分别落实；成功、警告、危险和信息保持明确语义，告警色只用于真实需要关注的状态 |
| 表面与边界 | 保留主题的冷暖、明度、描边、共容器、层次和材质关系，不用统一白卡或装饰盖过真实特征 |
| 形状分工 | 容器、按钮、输入、标签和浮层按主题选择圆角，不把所有元素统一成大圆角或胶囊 |
| 排版节奏 | 字号、字重、行高与层级按主题；中文有回退字体，数字采用稳定对齐，单位与读数一起出现 |
| 视觉特征 | 明确特色配方的真实内容条件、消费位置与无匹配时行为，不为模仿参考增加指标、图表或业务模块 |

图表沿用 `yida-rechart` 的 Canvas 主题契约；仅在用户明确要求复杂 ECharts option 或维护已有旧图表时转 `yida-chart`。多系列色板采用主题的数据语义，不将所有系列都染成高饱和品牌色。

## 验收依据

将选中主题的核心特征与偏离风险转成 `design.md` 的验收条件，结合 [页面质量门禁](page-quality-gates.md) 检查内容密度、空态、响应式与可访问性。差异来自主题与项目事实的组合，不靠强制选非常规颜色、加装饰或扩大字号跨度。
